# Git 
##Рабочая папка это папка с файлами проекта, в которой работаю
##Индекс это место, куда добавляются изменения для следующего коммита
##Коммит это сохранение изменений в Git
##Git и GitHab
Git это система контроля версийЮ которая работает на компьютере и хранит историю изменений проекта 
GitHab это интернет-сервис, который позволяет публиковать Git-репозиции и работать совместно с другими людьми 
##Использованные команды
git status показывает состояние рабочей папки и индекса
git diff  показывает изменения в рабочей папке, которые ещё добавлены в индекс
git diff --staged показывает измененияЮ которые уже добавлены в индекс и будут включены в следующий коммит
