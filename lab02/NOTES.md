# Git 
##Рабочая папка это папка с файлами проекта, в которой работаю
##Индекс это место, куда добавляются изменения для следующего коммита
##Коммит это сохранение изменений в Git
##Git и GitHub
##Git это система контроля версий, которая работает на компьютере и хранит историю изменений проекта 
##github - это интернет-сервис, который позволяет публиковать Git-репозиции и работать совместно с другими людьми 
##Использованные команды
##git status показывает состояние рабочей папки и индекса
##git diff  показывает изменения в рабочей папке, которые ещё добавлены в индекс
##git diff --staged показывает изменения, которые уже добавлены в индекс и будут включены в следующий коммит
##Ветки это отдельная линия разработки, которая указывает на определённый коммит. При создании нового коммита ветка перемещается и начинает указывать на новый коммит. Слияние оъединяет изменения из одной ветки с другой
