отличие git restore от git restore --source=...
git restore
по умолчанию берёт версию файла из последнего коммита и земаняет уго текущее изменения в рабочей папке. Оно используется для отмены коммитов
git restore --source=...
позволяет взять версию файла из любого указанного коммита и поместить её в рабочую папку.
