отличие git restore от git restore --source=...
git restore
по умолчанию берёт версию файла из последнего коммита и земаняет уго текущее изменения в рабочей папке. Оно используется для отмены коммитов
git restore --source=...
позволяет взять версию файла из любого указанного коммита и поместить её в рабочую папку.
git reset --hard перемещает указатель HEAD на выбранный коммит и удаляет изменения из рабочей директории и индекса. Если изменения не были сохранены, то они проподают
git revert не удаляет старый коммит, а создает новый, который отменяет изменения прошлого. История рот этом сохраняется. Поэтому revert безопаснее для коммитов, которые уже были отправлены в общий репозиторий
Ветка - подвижный указатель на последний коммит линии разработки
Тег - неподвижная метка конкретного коммита, которая обычно используется для обозначения версий
